- Синтаксическая проверка исходников и тестов TypeScript (85 файлов) с помощью `typescript.transpileModule`: ошибок синтаксиса нет.
- Контроль замен типографского длинного тире `-` в исходниках: заменено на обычный дефис `-` (352 вхождения, 79 файлов).

- `tsc --noEmit` не может запуститься полностью: отсутствуют устанавливаемые зависимости и определения типов (`bcryptjs`, `express`, `node` и другие).
- Интеграционные тесты требуют PostgreSQL и переменных окружения; в этой среде не запускались.
- Реальная проверка интерфейса браузером и тестирование с физическим терминалом/кассой не выполнялись.

Для полного прогона в пользовательской среде после настройки `.env` и PostgreSQL:

```bash
cd backend
npm ci
npm run prisma:generate
npm run typecheck
npm test
```

Перед реальным использованием ресторана необходимо проверить настройки оплаты, fiscal-провайдера и выбранную формулу стоимости дополнительных ингредиентов.
