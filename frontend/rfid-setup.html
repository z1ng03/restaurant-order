Три метки: оплата и возраст.

Учебная оплата: Arduino Uno + RC522 + RGB.

1. Подключение

Откройте эту страницу в Chrome или Edge на localhost. Закройте монитор порта Arduino и другие вкладки, использующие считыватель.

Считыватель не подключён.

2. Назначение карт

Нажмите кнопку и приложите нужную карту. Между действиями убирайте карту от антенны. Назначение сохраняется в Arduino.

Брелок официанта: не прочитано

Успех: не прочитано
Отказ: не прочитано

3. Привязка брелка к официанту

После назначения брелка в Arduino сохраните его за сотрудником. Повторная привязка заменяет предыдущий брелок этого сотрудника.

4. Проверка


После проверки нажмите «Отключить» и перейдите в меню ресторана. В корзине выберите оплату картой и подключите Arduino.

Зелёный означает одобрение учебной карты. Сохранение заказа подтверждает сайт после ответа сервера. Денежных операций нет.

Подключение проводов

Меняйте провода только при отключённом USB. RC522 питается от 3.3V. Выходы Uno на входы RC522 подключайте через четыре делителя: Uno → 1 кОм → вход RC522; от каждого входа RC522 → 2 кОм → GND.

УстройствоArduino Uno
RC522 SDA / SSD10 через делитель 1 кОм / 2 кОм
RC522 SCKD13 через делитель 1 кОм / 2 кОм
RC522 MOSID11 через делитель 1 кОм / 2 кОм
RC522 MISOD12
RC522 RSTD9 через делитель 1 кОм / 2 кОм
RC522 3.3V / GND / IRQ3.3V / GND / не подключать
RGB R / G / BD5 / D6 / D7, каждый через 330 Ом
RGB общий катод, «−»GND

Для RGB с общим анодом: общий контакт → 5V, в скетче COMMON_ANODE=true. Пищалка не используется; D4 оставлен свободным.
