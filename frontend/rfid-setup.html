Подключение проводов

Меняйте провода только при отключённом USB. RC522 питается от 3.3V. Выходы Uno на входы RC522 подключайте через четыре делителя: Uno → 1 кОм → вход RC522; от каждого входа RC522 → 2 кОм → GND.

УстройствоArduino Uno
RC522 SDA / SSD10 через делитель 1 кОм / 2 кОм
RC522 SCKD13 через делитель 1 кОм / 2 кОм
RC522 MOSID11 через делитель 1 кОм / 2 кОм
RC522 MISOD12
RC522 RSTD9 через делитель 1 кОм / 2 кОм
RC522 3.3V / GND / IRQ3.3V / GND / не подключать
RGB R / G / BD5 / D6 / D7, каждый через 330 Ом
RGB общий катод, «−»GND
Пассивный пьезоэлемент + / −D4 через 100–220 Ом / GND

Для RGB с общим анодом: общий контакт → 5V, в скетче COMMON_ANODE=true. Для активной пищалки измените ACTIVE_BUZZER=true. Для пищалки неизвестного тока используйте транзисторный ключ; подробности — в инструкции RFID_SETUP.md.
