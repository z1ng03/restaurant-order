ГОТОВЫЙ ПРОЕКТ «МЕНЮ + КОРЗИНА + RFID-ОПЛАТА»

Эта папка — клиентская часть. С сентября 2026 она работает поверх
настоящего backend (см. ../backend и ../README.md): меню, корзина и заказы
теперь настоящие данные из PostgreSQL, а не захардкоженный список и
localStorage. Перед запуском backend должен быть поднят на localhost:4000
(или другой адрес, указанный через window.RESTAURANT_API_BASE).

Также появились два новых экрана для персонала — kitchen.html (монитор
шеф-повара) и waiter.html (монитор официанта), и monitor-select.html —
страница для локальной разработки, чтобы выбрать столик без шести
физических мониторов.

ВОЗМОЖНОСТИ
- категории блюд, кальянов и отдельная категория «Алкоголь» (21+ считается
  сервером на основе состава заказа, а не только категории);
- подробное описание, состав и аллергены — из базы данных;
- доступность блюда считается сервером (рецепт + остатки на складе);
- дополнительные опции к блюду (например, доп. сыр) прямо в карточке блюда;
- изменение количества и полная очистка корзины;
- подтверждение возраста 21+ официантом (логин/пароль) перед оплатой —
  клиент сам подтвердить возраст больше не может;
- два способа оплаты: наличными и Kaspi QR (в учебном проекте оплата Kaspi
  QR имитируется через тот же RFID-считыватель, что и раньше);
- ожидание ответа Arduino: PAYMENT_APPROVED или PAYMENT_DECLINED;
- отдельные окна успешной оплаты, отказа и отказа от подтверждения возраста;
- демонстрация обоих ответов без подключённого оборудования;
- мониторы кухни и официанта с реальными статусами заказов.

ЗАПУСК БЕЗ ARDUINO
1. Поднимите backend (см. ../README.md — миграции + npm run seed + npm run dev).
2. Откройте index.html?monitor=1 (или monitor-select.html, чтобы выбрать
   столик мышкой — это чисто для разработки, на реальном киоске не нужно).
3. Добавьте товары и перейдите в корзину.
4. Для проверки RFID-оплаты откройте блок «Демонстрация без Arduino»
   и выберите PAYMENT_APPROVED или PAYMENT_DECLINED.

ЗАПУСК С ARDUINO И RC522
1. Установите в Arduino IDE библиотеку MFRC522.
2. Подключите RC522 к Arduino Uno/Nano:
   SDA/SS -> D10
   SCK    -> D13
   MOSI   -> D11
   MISO   -> D12
   RST    -> D9
   3.3V   -> 3.3V (не подключать к 5V)
   GND    -> GND
3. Загрузите скетч arduino/rc522_payment.ino.
4. Закройте Serial Monitor, чтобы он не занимал COM-порт.
5. Запустите start_server.bat. Проект откроется по адресу localhost:8000.
6. Используйте Chrome или Edge, выберите оплату картой и нажмите
   «Подключить RFID-считыватель».
7. В системном окне выберите COM-порт Arduino и приложите RFID-карту.

Протокол Serial: 9600 бод. Сайт отправляет START_PAYMENT и ждёт строку
PAYMENT_APPROVED или PAYMENT_DECLINED, завершённую переводом строки.

По умолчанию APPROVE_ANY_CARD = true, поэтому для демонстрации принимается
любая совместимая RFID-карта. Для проверки по UID установите false и замените
DE AD BE EF в AUTHORIZED_UIDS на UID своей карты.

ВАЖНО
RC522 читает совместимые RFID-карты/метки и не является банковским терминалом.
Представленная «оплата картой» — учебная имитация. Для реального приёма
банковских платежей необходим сертифицированный платёжный терминал и backend.

ОСНОВНЫЕ ФАЙЛЫ
- index.html — меню;
- cart.html — корзина и оплата;
- kitchen.html / kitchen.js — монитор шеф-повара (новое);
- waiter.html / waiter.js — монитор официанта (новое);
- monitor-select.html — выбор столика для локальной разработки (новое);
- style.css / staff.css — оформление;
- script.js — меню, корзина, 21+, способы оплаты;
- api.js — обёртка над fetch для запросов к backend (новое);
- session.js — открытие/хранение сессии столика (новое);
- staff-auth.js — вход для персонала на kitchen.html/waiter.html (новое);
- serial-payment.js — Web Serial клиент для RC522 (вынесено из script.js);
- arduino/rc522_payment.ino — скетч Arduino;
- start_server.bat — локальный сервер для Web Serial;
- images — изображения категорий.

Меню, корзина и заказы хранятся в PostgreSQL через backend — не в
localStorage. sessionStorage браузера хранит только id текущей сессии
столика и токен персонала, чтобы они сохранялись между index.html,
cart.html и обновлением страницы.
