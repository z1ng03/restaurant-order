ГОТОВЫЙ ПРОЕКТ «МЕНЮ + КОРЗИНА»

1. Распакуйте архив.
2. Откройте файл index.html в браузере.
3. Выберите категорию и нажмите «Добавить».
4. Нажмите на большую кнопку корзины справа.
5. Нажмите на фотографию блюда, чтобы увидеть описание, состав,
   энергетическую ценность и сведения об аллергенах.

Файлы:
- index.html — страница меню;
- cart.html — отдельная страница корзины;
- style.css — оформление обеих страниц;
- script.js — категории, добавление блюд, изменение количества и расчёт суммы;
- images — встроенные изображения категорий.

Корзина хранится в localStorage браузера, поэтому выбранные блюда сохраняются
при переходе между страницами и после обновления страницы.
